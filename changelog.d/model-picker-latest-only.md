### Changed

- The model picker shows only the newest model of each family, such as Claude Opus 5.5 and not
  Claude Opus 5 or 4.8. "Show older models" at the end of the list shows the others, and "Show fewer
  models" hides them again. The model that the agent runs and the default model always stay in the
