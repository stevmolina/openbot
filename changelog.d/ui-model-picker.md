### Added

- In the simple layout, the message bar shows the agent's model next to Send. Click it to change the
  model, the provider, the reasoning effort or the speed without leaving the chat.
- The model picker has one search field for the models of all providers, and a Recent view with the
  models that you used last.

### Changed

- The model picker shows each provider with its name and a status dot. Providers that are not
  connected stay in the list, dimmed, under "Not connected", with a Connect or Set up button.
- Each model in the picker shows its short description. Fast mode is now a Standard and Fast control,
  as the effort is.
