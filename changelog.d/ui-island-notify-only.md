### Changed

- The Dynamic Island now works like a notification. It stays hidden, and it appears only when
  something needs you: an agent question, an approval, a browser handover, or a failed turn. A new
  reply from an agent shows for a few seconds, then hides. The hidden island does not cover the
  notch or take clicks, so it no longer conflicts with other notch apps.
- Settings → Dynamic Island: "Show idle island" is now off by default. A new switch, "Show agent
  activity", is also off by default. Turn them on to see the island while agents run or when
  nothing needs you. A choice you saved before stays as you saved it.
